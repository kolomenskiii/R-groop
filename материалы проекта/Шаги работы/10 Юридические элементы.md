# Шаг 10. Подготовить юридические элементы и подвал

**Модель перед выполнением:** Luna для учебной подписи; Sol для юридической применимости настоящего сайта. Сначала определить сценарий без чтения юридических источников. Применить [правило выбора модели](<Расход и модели.md>), предложить переключение при необходимости и дождаться ответа пользователя до выполнения задачи. Если ответ для этого шага уже получен, не спрашивать повторно.

Общие правила и согласования: [навигация](<00 Навигация.md>).

Начинать после завершения и согласования шага 9. **Первым делом определить назначение сайта — до чтения юридического чек-листа, документов и внешних источников.**

Использовать ответ пользователя из шага 1 и файла состояния. Если ответ уже известен, повторно не спрашивать. Если неизвестен, уточнить: это учебный сайт для портфолио или сайт для настоящего клиента? До ответа не начинать юридический анализ.

## Если сайт учебный или для портфолио

Добавить в подвал только надпись:

> Сайт создан в рамках бесплатного обучения Крупиной Татьяны.

На этом работа по шагу завершена. Не читать юридический чек-лист и файл для настоящего клиента, не проверять документы, не изучать законодательство, не анализировать применимость юридических требований и не создавать юридические документы или отчёты.

Показать пользователю подвал с надписью и получить согласование.

## Если сайт для настоящего клиента

Только после подтверждения этого сценария открыть [юридические инструкции для клиента](<Юридические элементы для клиента.md>) и выполнить применимые действия из них. Ссылка на чек-лист и подробности находятся в этом отдельном файле.

**Результат:** для учебного сайта — согласованная надпись в подвале; для настоящего клиента — согласованные применимые юридические элементы. К шагу 11 переходить только после завершения выбранной ветки и согласия пользователя.
