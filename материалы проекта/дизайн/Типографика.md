# Типографика новой дизайн-системы — предложение

Дата: 16.11.2026. Статус: на согласовании.

Исходный выбор пользователя: **Tektur Black Condensed** для заголовков; весь сайт — на кириллице. Старые UI kit, Cygre и другие стили папки относятся к предыдущему проекту и не задают направление нового сайта.

## Шрифтовая пара

| Роль | Семейство и вес | Применение |
| --- | --- | --- |
| Акцентные заголовки | Tektur Black Condensed, 900, `wdth: 75` | H1 и короткие H2 |
| Основной текст | Onest Regular, 400 | Абзацы, карточки, поля форм |
| Интерфейс | Onest Medium 500 / SemiBold 600 | Меню, подписи / кнопки |

**Onest — предложение, пока не согласованное пользователем.** Его спокойные открытые формы дают читаемый текст рядом с плотной угловатой формой Tektur. Использовать Tektur дозированно: длинные русские фразы и мелкие подписи набирать Onest.

[Метаданные Tektur](https://github.com/google/fonts/blob/main/ofl/tektur/METADATA.pb) подтверждают кириллический набор, лицензию OFL и оси `wdth` 75–100, `wght` 400–900. [Метаданные Onest](https://github.com/google/fonts/blob/main/ofl/onest/METADATA.pb) подтверждают кириллицу, OFL и веса 100–900. Файлы для нового проекта ещё не добавлены, поэтому фактический рендер кириллицы и переносы пока не проверены.

## Предварительная шкала

| Роль | Компьютер | Телефон | Интерлиньяж |
| --- | --- | --- | --- |
| H1 | Tektur 72–96 px | 42–56 px | 0.95–1.05 |
| H2 | Tektur 48–64 px | 32–40 px | 1.0–1.1 |
| H3 | Onest SemiBold 28–36 px | 24–28 px | 1.15–1.25 |
| Основной текст | Onest Regular 18 px | 16 px | 1.5–1.6 |
| Подпись | Onest Medium 14 px | 14 px | 1.35–1.45 |
| Кнопка | Onest SemiBold 16 px | 16 px | 1.2 |

Размеры предварительны: их следует проверить на реальных текстах и экранах. Не уплотнять Tektur отрицательным межбуквенным интервалом без визуальной проверки. Длинные заголовки сокращать или переносить осмысленно.

**Обязательное ограничение для всех страниц:** не ставить над H1/H2 декоративный подзаголовок вида «02 / НАЗВАНИЕ РАЗДЕЛА» и не размещать поясняющий подзаголовок справа от H1/H2. Это запрещённые элементы композиции. H1/H2 занимает всю доступную ширину контентной области без собственного `max-width` и без узкой колонки. См. [правила композиции](<Композиция и переходы.md>).

```css
:root {
  --font-display: "Tektur", sans-serif;
  --font-body: "Onest", system-ui, sans-serif;
}

.heading-display {
  font-family: var(--font-display);
  font-weight: 900;
  font-variation-settings: "wdth" 75, "wght" 900;
}

body, button, input, textarea {
  font-family: var(--font-body);
}
```

Перед использованием в Tilda подключить кириллические версии обоих семейств и проверить загрузку осей и начертаний на опубликованной странице.
