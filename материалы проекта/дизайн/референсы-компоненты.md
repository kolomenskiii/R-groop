## Основные имена компонентов

- `highlight`: `highlight`.
- `folders`: `folder, folder--blue, folder--sun, icon-menu`.
- `tags`: `tag, tag--down, tag--blue, tag--matcha`.
- `slide`: `slide-cta, slide-cta__knob, slide-cta__text`.
- `files`: `file, file__thumb--sticker, file__label`.
- `doc`: `file__doc, file__zip, file__video`.
- `eyebrow`: `eyebrow`.
- `dock`: `dock, dock__item, dock__cta`.
- `notice`: `notice, notice__action`.
- `quote`: `quote-card`.
- `frame`: `photo-frame, photo-frame--blue, photo-frame--matcha`.

Имена помогают находить образцы; CSS-свойства не восстановлены из отсутствующих файлов. При работе в Tilda воспроизводить выбранные компоненты HTML/CSS/JS внутри T123: одна секция сайта — один блок. Весь HTML витрины на сайт не вставлять; перенос в элементы Zero Block не выполнять.
