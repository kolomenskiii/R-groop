# Главная страница ООО «Р-Групп»

Локальный статический сайт направления «Доставка инертных материалов». Файлы сайта находятся в корне репозитория: `index.html`, `styles.css`, `script.js` и `assets/`. Откройте `index.html` через Live Server или любой статический HTTP-сервер. При публикации через GitHub Pages выберите ветку репозитория и папку `/ (root)`.

Инструкции, дизайн, аналитика, референсы и остальные рабочие материалы сохранены в [папке проекта](<материалы проекта/>). При загрузке на GitHub добавляйте весь репозиторий, включая эту папку и скрытые файлы. `.gitignore` в проекте нет.

Страница использует фотографию, предоставленную пользователем. Шрифты Tektur и Onest загружаются из Google Fonts; при отсутствии доступа применяются системные. Форма создаёт письмо через `mailto:` и не хранит заявки. Для приёма заявок без почтовой программы потребуется подключить обработчик формы. Текстовое обозначение компании в шапке заменяется на исходный логотип после его получения.

Карта загружается из Яндекс Карт и требует доступа к интернету. Контактные данные взяты из ТЗ пользователя. Цены, сроки и производственные показатели не указаны, поскольку подтверждённых данных нет.
